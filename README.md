# Future Memories

Sito di fotografia e video di matrimonio. Next.js (App Router, JavaScript) e Tailwind CSS 4.

## Avvio

```bash
npm install
cp .env.example .env.local   # inserire la chiave Web3Forms
npm run dev
```

## Dove modificare i contenuti

- `data/site.js`: contatti, social, file media (showreel, logo, foto)
- `data/services.js`: i 7 servizi
- `data/phases.js`: le 6 fasi di lavoro
- `data/portfolio.js`: i matrimoni del portfolio (video Vimeo e gallerie)
- `public/`: immagini e video, tutti nella root senza sottocartelle

Il facsimile grafico della cliente è in `docs/facsimile.pdf`.
